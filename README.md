# Kommentar till förvaltningslagen (2017:900)

Kommentar till svensk författning: **Förvaltningslag (2017:900)** (SFS 2017:900). Kommentaren omfattar **50 enheter** (49 paragrafer samt övergångsbestämmelserna) fördelade på 3 kommentarskapitel; vid varje paragraf återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2025:582** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2025-10-17).

## Innehåll

Se [INDEX.md](INDEX.md). Metoden beskrivs i [00-inledning.md](00-inledning.md).

## Metod

Kommentaren har utarbetats **uteslutande på grundval av lokalt material** (den officiella konsoliderade texten i SFS och författningsregistret), utan användning av kommersiella juridiska databaser. Lydelsen har maskinellt hämtats ordagrant ur den officiella texten. **Rättspraxis ingår inte i denna version** – den kommer att läggas till i ett senare skede.
